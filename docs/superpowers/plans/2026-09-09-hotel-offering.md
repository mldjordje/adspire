# Hotel offering — approved implementation

Custom hotel website / booking / management development, SR/EN/DE. One canonical landing per language, linked from homepage, navigation, services and relevant existing pages. Existing Adspire logo, navigation and footer frame a dark architectural visual concept.

## Design and implementation
- Hero: oversized Syne typography, cool blue accent, layered HTML hotel site/calendar against a warm generated architectural image. Image is illustrative, not a client reference.
- Scroll narrative: website → booking → reception calendar. Desktop sticky presentation, short normal-flow sections on mobile. Role tabs support keyboard navigation. Respect reduced motion.
- Content: three scoped phases, conditional integrations, no invented prices or performance guarantees. Clear zero Adspire commission explanation and separate running costs.
- Reuse quick inquiry endpoint and validation; optional localized copy and embedded hotel mode preserve existing callers. Demonstration interactions never send real inquiries.
- Add service to catalog, translations and inquiry selector. Redirect service alias, metadata/hreflang, sitemap, Service/WebPage/Breadcrumb/FAQ and factual llms profiles.

## Verification and publication
Typecheck, catalog/SEO/form regression tests, production build. Browser verification at desktop/mobile for each locale, role/date interactions, CTA paths, reduced motion and no overflow. Test forms with mocked network only. Commit only task files and push to production as explicitly requested; confirm deployment and public URLs.

## Sitemap
The existing sitemap index URL remains unchanged. Build regenerates its child sitemap. Existing Search Console submission does not require a new file upload. New URLs can be requested individually for indexing; indexing and AI citations are external outcomes.
